## 🚀 Como Rodar Localmente

```bash
# Clone o repositório
git clone https://github.com/geconias7/GEHTECH27.git

# Entre na pasta
cd GEHTECH27

# Instale as dependências
npm install

# Rode em modo desenvolvimento
npm run dev

# Build para produção
npm run build
```
