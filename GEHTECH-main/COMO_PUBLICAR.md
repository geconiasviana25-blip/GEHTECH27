# 🚀 COMANDOS PARA PUBLICAR NO GITHUB

## ✅ Passo a Passo Completo

### 1️⃣ Criar Repositório no GitHub
- Acesse: https://github.com/new
- Nome: `GEHTECH27`
- Marque como **Público**
- Clique em **Create repository**

### 2️⃣ Executar Comandos no Terminal

Abra o terminal na pasta do projeto e copie/cole estes comandos:

```bash
# Inicializar git
git init

# Adicionar todos os arquivos
git add .

# Fazer primeiro commit
git commit -m "🚀 GEH TECH 27 - Site completo com blog, templates e painel admin"

# Adicionar repositório remoto
git remote add origin https://github.com/geconias7/GEHTECH27.git

# Renomear branch para main
git branch -M main

# Enviar para o GitHub
git push -u origin main
```

### 3️⃣ Ativar GitHub Pages (Site Online)

1. Vá para: https://github.com/geconias7/GEHTECH27
2. Clique em **Settings** ⚙️
3. No menu lateral, clique em **Pages**
4. Em **Build and deployment**:
   - **Source:** GitHub Actions
5. O workflow já está configurado! Aguarde 2-3 minutos
6. Seu site estará em: **https://geconias7.github.io/GEHTECH27/**

## 💡 Dicas

1. **Primeira vez usando Git?**
   - Configure seu nome: `git config --global user.name "Seu Nome"`
   - Configure seu email: `git config --global user.email "seu@email.com"`

2. **Problemas com autenticação?**
   - Use GitHub CLI: https://cli.github.com/
   - Ou crie um Personal Access Token: https://github.com/settings/tokens

3. **Quer um domínio personalizado?**
   - Configure em Settings > Pages > Custom domain
   - Exemplo: `gehtech27.com`
